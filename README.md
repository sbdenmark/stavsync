# Stav-synk

Android-app, der holder billige Magic Lantern-lysstave (Bluetooth, MELK) i takt.

- Forbinder til flere stave på én gang og husker dem.
- Indbyggede effekter, effekt-finder og auto-genstart, så effekterne ikke glider fra hinanden.
- Egne effekter, der styres af appen: blink, fade, strobe, jagt, skiftevis.
- Musikstyring fra mikrofonen eller direkte fra telefonens egen lyd (fx YouTube eller Spotify).
- Kører videre i baggrunden med en fast notifikation og en Stop-knap.

## Installér

1. Åbn **Releases** til højre på repoets forside på telefonen.
2. Hent **Stav-synk.apk** fra den nyeste udgivelse.
3. Åbn filen, og tillad installation fra ukendte kilder, hvis Android spørger.

Nye versioner bygges automatisk, hver gang koden ændres, og kan installeres oven på den gamle.
